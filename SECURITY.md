# 安全报告 / Security reporting

发现本插件导致凭证泄露、越权或其他安全漏洞，请使用 [GitHub 私密漏洞报告](https://github.com/g-yixuan/dsh-sidenote/security/advisories/new)，不要在公开 Issue 中提交漏洞细节或凭证。

提供受影响的插件和 DSH 版本、复现步骤、影响及可能的修复方式。请移除真实 token、私人会话和工作区内容。维护者按可用时间处理，不承诺固定响应时间。

安全修复优先面向最新发布版本；其他版本是否回补由维护者依据影响评估。普通功能缺陷和使用问题仍通过 Issues 处理。

## English

Report credential exposure, unauthorized access, or other security vulnerabilities through [GitHub private vulnerability reporting](https://github.com/g-yixuan/dsh-sidenote/security/advisories/new). Do not post exploit details or credentials in a public issue.

Include affected plugin and DSH versions, reproduction steps, impact, and possible fixes. Remove real tokens, private sessions, and workspace content. Maintainers respond as time allows; there is no guaranteed response time.

Security fixes target the latest published version first. Maintainers assess backports based on impact. Ordinary bugs and usage questions belong in Issues.
